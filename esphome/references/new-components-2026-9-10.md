# New components and platforms since Aurora v1.19.0

> *Generated by [aurora@aurora-smart-home (esphome skill)](https://github.com/tonylofgren/aurora-smart-home)*

Baseline: Aurora v1.19.0, 2026-08-29. Verified on 2026-10-22 against ESPHome
2026.10.0 schemas and the official September/October release lists. This inventory
distinguishes user-configurable components from internal libraries and changes tagged
"new-component" that extend an existing API. Do not invent standalone YAML for internals.

Read [package instructions](../assets/templates/2026-10/README.md) before using an example.
Files are independent package fragments except the standalone host example. Hardware,
entity IDs, private bind keys and electrical interfaces must be confirmed for a real build.

conflict with a 2026.10 schema. A new component does not imply support on every chip.
